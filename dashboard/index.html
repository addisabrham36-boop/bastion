How to Connect & Protect Your Website

Step-by-step instructions to route traffic for any website you own or manage through Bastion WAF.

1

Verify Site Ownership & Permission

Bastion WAF acts as an inline reverse proxy. Ensure you own or have explicit administrative authorization to protect the target domain or application server.

2

Add Domain & Upstream Address

Click "Add a Website Now" above or go to Protected Domains tab and click "Add New Upstream Target". Enter your domain (e.g. mywebsite.com) and the address of your backend web server (e.g. http://192.168.1.50:8000 or http://127.0.0.1:3000).

3

Point Traffic to Bastion WAF (Port 8080)

Direct incoming client requests to the Bastion WAF reverse proxy on Port 8080 (via DNS A-record, load balancer, or port forwarding). Bastion inspects all requests in sub-milliseconds and transparently forwards clean traffic to your upstream server.

4

Monitor Real-Time Threats

View live intercepts in the Overview and Security Audit Logs tabs. Toggle any of the 100+ rules on or off dynamically without restarting the server.

Self-Hosting Deployment Guide

How to deploy Bastion WAF on your own VPS, cloud server, or bare-metal machine.

A

Prerequisites

A Linux server (Ubuntu 20.04+, Debian 11+, CentOS 8+, or similar) with Python 3.10+ and pip installed. Minimum 512 MB RAM, 1 vCPU.

B

Install Bastion WAF

# Clone the repository
git clone https://github.com/addisabrham36-boop/bastion.git
cd bastion

# Create virtual environment and install dependencies
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Install as CLI command
pip install -e .
C

Run Bastion (Quick Start)

# Start with default settings
bastion

# Or specify a custom upstream target
bastion --upstream http://127.0.0.1:3000

# Bind to all interfaces (for remote access)
bastion --host 0.0.0.0
D

Run as a Systemd Service (Production)

Create a systemd service so Bastion starts on boot and auto-restarts on failure: 

# Create the service file
sudo nano /etc/systemd/system/bastion-waf.service

# Paste the following:
[Unit]
Description=Bastion WAF - Web Application Firewall
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/bastion
ExecStart=/opt/bastion/venv/bin/bastion --host 0.0.0.0
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

# Enable and start:
sudo systemctl daemon-reload
sudo systemctl enable bastion-waf
sudo systemctl start bastion-waf
sudo systemctl status bastion-waf
E

Nginx Reverse Proxy + SSL (Optional)

Put Nginx in front for SSL termination (HTTPS). Certbot provides free certificates: 

# Install Nginx and Certbot
sudo apt install nginx certbot python3-certbot-nginx

# Nginx config (/etc/nginx/sites-available/bastion)
server {
    listen 80;
    server_name your-domain.com;

    # Dashboard
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # WAF Proxy
    location /waf/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

# Enable site and get SSL certificate
sudo ln -s /etc/nginx/sites-available/bastion /etc/nginx/sites-enabled/
sudo certbot --nginx -d your-domain.com
sudo systemctl restart nginx
F

Firewall Configuration

# Allow HTTP/HTTPS and Bastion ports
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 8000/tcp   # Dashboard
sudo ufw allow 8080/tcp   # WAF Proxy
sudo ufw enable
